# Insubria Hub

App per studenti e personale dell'Università dell'Insubria (Varese, Como, Busto Arsizio).

- `index.html`: prototipo pubblicato come artifact su Claude (libretto, community, eventi, assistente AI, area staff con moderazione).
- `app/`: versione autonoma installabile come web app, con server Node, notifiche push su Android, iOS, macOS e Windows, moderazione lato server e assistente Claude. Istruzioni in [`app/README.md`](app/README.md).

Il nome Insubria Hub è provvisorio. Il progetto non è un servizio ufficiale dell'ateneo.
